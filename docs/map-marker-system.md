# Map marker system

Proposed global contract, applied in round 4 of the prototype. Use the same vocabulary in Map, itinerary rows, the key and the visitor/editor layouts.

| Information                            | Encoding                                                                               | Meaning                                                                                                                                                               |
| -------------------------------------- | -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Planned stop type                      | Icon inside a circle                                                                   | Feather = birding; house = accommodation; plane = airport; cup = food; location symbol = waypoint                                                                     |
| Future / past                          | Hollow / filled circle                                                                 | Compared with the snapshot clock. No distinct present state. Filled means past, not completed or visited                                                              |
| Selected stop                          | Amber outer halo                                                                       | Preserve its underlying type and hollow/filled state; selection is not a new type or status                                                                           |
| Multiple selected stops                | Same halo on each                                                                      | Used only in the editor's bulk-selection flow                                                                                                                         |
| Evidence of a checklist in a stop area | Separate ✓ and checklist count in the itinerary/details                                | Never infer this from the clock, icon fill, or a species sighting alone                                                                                               |
| Report checklist location              | Blue location pin                                                                      | Flame for an eBird hotspot, dot for a personal location. The prototype uses eBird-style pin semantics drawn with Bootstrap Icons, not an official eBird artwork asset |
| Nearby report checklists               | Blue numbered circle                                                                   | Number of unique checklist IDs; zoom to expand. All pins remain checklist data rather than planned stops                                                              |
| Historical EBD locations               | Green hotspot / ochre personal-location circles; radius increases with checklist count | Enabled in the editor and disabled in visitor/preview. Popover shows checklist and species counts                                                                     |
| Species reporting rates                | Orange scale plus circle size                                                          | Colour is rate, size is checklist effort. Keep its legend separate from itinerary temporal/selection semantics                                                        |

Do not assign a different colour to every stop type. Teal consistently belongs to planned itinerary stops; blue belongs to reported checklists; amber belongs to selection; orange is reserved for the quantitative species layer. The symbol and shape carry meaning even without colour. Selected stop markers are buttons with accessible type, name and temporal labels. A compact Map key explains all channels.

No GPS track is implied by a line. Routes are planned/cached driving geometry from the itinerary, not performed tracks. Report checklists outside all planned stop areas still appear on the map; do not snap them to a stop or hide them.

In visitor/preview, report checklists are always displayed when available; historical EBD and species reporting-rate layers are initially off. Extra layers are tucked behind an optional button rather than occupying the default map. Opening an eBird report in visitor/preview follows a direct link to eBird without a configuration dialog.

Round 5 adds a draggable selected stop marker and four area handles in editor mode. During dragging the geometry previews immediately; release recomputes report membership and historical EBD species totals. Moving a centre invalidates the incoming and outgoing drive estimates; resizing keeps routes. Hover shows one brief map summary, click pins it for links, and clicking empty map closes it.
